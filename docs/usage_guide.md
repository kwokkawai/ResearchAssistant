# 智能体和模型选择功能说明

## 🎯 新功能概述

现在您可以在研究助手中选择特定的智能体和LLM模型来进行研究！

## 🤖 智能体选择

### 可用的智能体：
- **研究助手** 🔍: 通用研究分析
- **技术专家** 💻: 技术问题分析
- **学术专家** 🎓: 学术研究分析
- **商业分析师** 📊: 商业策略分析

### 使用方法：
1. 在"选择智能体"部分点击您需要的智能体
2. 选中的智能体会显示蓝色边框
3. 可以选择多个智能体进行并行分析

## 🧠 LLM模型选择

### 可用的模型：
- **OpenAI GPT** ☁️: GPT-4o, GPT-4-turbo, GPT-3.5-turbo
- **Google Gemini** 🌟: Gemini-1.5-pro, Gemini-1.5-flash
- **Ollama** 🖥️: 本地LLM模型 (llama2等)

### 使用方法：
1. 在"选择LLM模型"部分点击您想要的模型
2. 选中的模型会显示绿色边框
3. 只有可用的模型才能被选择
4. 选择的模型会显示在"开始研究"按钮旁边

## 🔄 工作流程

1. **输入研究问题**: 在文本框中输入您的研究问题
2. **选择智能体**: 点击一个或多个智能体卡片
3. **选择模型**: 点击一个可用的LLM模型
4. **开始研究**: 点击"开始研究"按钮
5. **查看结果**: 系统会显示综合总结和各智能体的详细分析

## 💡 使用建议

### 智能体组合建议：
- **技术问题**: 选择"技术专家" + "研究助手"
- **学术研究**: 选择"学术专家" + "研究助手"
- **商业分析**: 选择"商业分析师" + "研究助手"
- **全面分析**: 选择所有智能体

### 模型选择建议：
- **最佳质量**: OpenAI GPT-4o 或 Google Gemini-1.5-pro
- **快速响应**: GPT-3.5-turbo 或 Gemini-1.5-flash
- **隐私保护**: Ollama (本地模型)
- **成本考虑**: GPT-3.5-turbo 或 GPT-4o-mini

## ⚠️ 注意事项

1. **模型可用性**: 只有状态为"可用"的模型才能被选择
2. **API密钥**: 确保已配置相应的API密钥
3. **网络连接**: 云端模型需要网络连接
4. **响应时间**: 不同模型的响应时间可能不同

## 🐛 故障排除

### 如果模型不可用：
1. 检查API密钥是否正确配置
2. 确认网络连接正常
3. 查看控制台错误信息

### 如果智能体无响应：
1. 尝试选择不同的模型
2. 检查查询是否过于复杂
3. 减少同时选择的智能体数量

## 🚀 开始使用

1. 启动应用: `python run.py`
2. 访问: `http://localhost:5050`
3. 按照上述步骤选择智能体和模型
4. 输入研究问题并开始分析

享受您的新研究助手体验！ 🎉
