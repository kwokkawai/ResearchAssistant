# OpenAI 模型说明

## 当前可用的OpenAI模型

### 1. GPT-4o (`gpt-4o`) ⭐ (推荐)
- **描述**: OpenAI最新的多模态模型
- **特点**: 
  - 支持文本、图像和音频输入
  - 强大的多模态理解能力
  - 更快的响应速度
  - 更低的成本
- **适用场景**: 复杂分析、多模态内容处理、研究任务

### 2. GPT-4 Turbo (`gpt-4-turbo`)
- **描述**: GPT-4的改进版本
- **特点**:
  - 更高的性能
  - 更低的成本
  - 支持更长的上下文
- **适用场景**: 复杂文本生成、深度分析

### 3. GPT-4 (`gpt-4`)
- **描述**: 经典的高级模型
- **特点**:
  - 强大的自然语言理解
  - 高质量的输出
  - 稳定的性能
- **注意**: 计划于2025年4月30日停止使用
- **适用场景**: 复杂任务、高质量输出需求

### 4. GPT-3.5 Turbo (`gpt-3.5-turbo`)
- **描述**: 快速且经济的模型
- **特点**:
  - 快速响应
  - 成本效益高
  - 广泛适用
- **适用场景**: 日常任务、快速响应需求

### 5. GPT-4o Mini (`gpt-4o-mini`)
- **描述**: 轻量级多模态模型
- **特点**:
  - 更小的模型尺寸
  - 更低的成本
  - 保持良好性能
- **适用场景**: 成本敏感的应用、高频查询

## 配置示例

### 环境变量配置
```bash
# 使用GPT-4o（推荐）
OPENAI_MODEL=gpt-4o

# 使用GPT-4 Turbo
OPENAI_MODEL=gpt-4-turbo

# 使用GPT-3.5 Turbo（经济选择）
OPENAI_MODEL=gpt-3.5-turbo

# 使用GPT-4o Mini（轻量级）
OPENAI_MODEL=gpt-4o-mini
```

### API调用示例
```python
# 在代码中动态选择模型
def get_openai_model(task_type):
    if task_type == "multimodal":
        return "gpt-4o"
    elif task_type == "complex_analysis":
        return "gpt-4-turbo"
    elif task_type == "fast_response":
        return "gpt-3.5-turbo"
    elif task_type == "cost_sensitive":
        return "gpt-4o-mini"
    else:
        return "gpt-4o"
```

## 模型选择建议

| 任务类型 | 推荐模型 | 原因 |
|---------|---------|------|
| 多模态分析 | `gpt-4o` | 支持图像、音频输入 |
| 复杂研究 | `gpt-4-turbo` | 强大分析能力，成本适中 |
| 快速响应 | `gpt-3.5-turbo` | 快速且经济 |
| 成本敏感 | `gpt-4o-mini` | 轻量级，成本低 |
| 高质量输出 | `gpt-4` | 经典稳定（即将停用） |

## 注意事项

1. **API密钥**: 需要有效的OpenAI API密钥
2. **配额限制**: 不同模型有不同的使用配额和限制
3. **成本考虑**: GPT-4o和GPT-4-turbo成本较高，GPT-3.5-turbo成本较低
4. **功能差异**: GPT-4o支持多模态，其他模型主要支持文本
5. **模型停用**: GPT-4计划于2025年4月30日停止使用
