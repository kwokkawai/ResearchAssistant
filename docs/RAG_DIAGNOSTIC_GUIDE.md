## 🔧 如何使用诊断页面

### 访问方式

1. **自动打开**:
   ```bash
   python3 open_diagnostic.py
   ```

2. **手动访问**:
   - 浏览器打开: http://localhost:5050/diagnostic
   - 或点击主应用中的"诊断"链接

### 诊断步骤

#### 1️⃣ 系统信息
自动显示当前浏览器和页面信息，确认您的环境。

#### 2️⃣ API端点检测
点击"🔍 检测API端点"按钮：
- ✅ **成功**: 显示API端点地址和状态
- ❌ **失败**: 说明Flask应用未运行或端口不正确

#### 3️⃣ RAG状态检查
点击"✅ 检查RAG状态"按钮：
- ✅ **可用**: RAG系统正常，可以加载文档
- ❌ **不可用**: 显示错误原因（通常是模型未下载）

#### 4️⃣ 文档加载测试
1. 在文本框中输入文档路径（每行一个）:
   ```
   /Users/pkwok/DocBase/AI/
   /Users/pkwok/Documents/test.pdf
   ```

2. 可选：勾选"强制重新加载"

3. 点击"📁 测试文档加载"

4. 查看结果：
   - ✅ 成功：显示加载的文档信息
   - ❌ 失败：显示详细错误信息

#### 5️⃣ 实时日志
所有操作都会记录在日志区域，便于追踪问题。

## 🐛 常见问题排查

### 问题1: 无法连接到服务器

**症状**: 诊断页面显示"连接失败"

**可能原因**:
1. Flask应用未运行
2. 端口被占用
3. 浏览器缓存

**解决方案**:
```bash
# 1. 检查Flask是否运行
curl http://localhost:5050/api/rag/status

# 2. 如果没有响应，重启应用
pkill -f 'python3 app.py'
python3 app.py

# 3. 硬刷新浏览器
# Mac: Cmd + Shift + R
# Windows/Linux: Ctrl + Shift + R
```

### 问题2: RAG系统不可用

**症状**: RAG状态检查显示"不可用"

**可能原因**:
1. AI模型未下载（首次运行）
2. 网络问题
3. 依赖包缺失

**解决方案**:
```bash
# 1. 下载RAG模型
python3 init_rag_models.py

# 2. 重启应用
pkill -f 'python3 app.py'
python3 app.py
```

### 问题3: 文档加载失败

**症状**: 测试文档加载返回错误

**可能原因**:
1. 文件路径不存在
2. 权限不足
3. 文件格式不支持
4. RAG系统不可用

**解决方案**:
1. **检查路径**:
   ```bash
   ls -la /Users/pkwok/DocBase/AI/
   ```

2. **检查权限**:
   ```bash
   ls -ld /Users/pkwok/DocBase/AI/
   # 应该显示 drwxr-xr-x
   ```

3. **检查文件格式**:
   支持的格式: `.pdf`, `.docx`, `.doc`, `.md`, `.txt`, `.json`, `.html`

4. **查看详细错误**:
   诊断页面会显示完整的错误响应，包括：
   - 错误类型
   - 错误消息
   - 失败的文件路径

## 🎯 调试工作流

```
1. 打开诊断页面
   ↓
2. 检测API端点
   ├─ 成功 → 继续
   └─ 失败 → 重启Flask
   ↓
3. 检查RAG状态
   ├─ 可用 → 继续
   └─ 不可用 → 下载模型
   ↓
4. 测试文档加载
   ├─ 成功 → 问题已解决
   └─ 失败 → 查看详细错误
   ↓
5. 根据错误修复
   ↓
6. 重新测试
   ↓
7. 在主应用中验证
```

## 💡 调试技巧

### 1. 使用浏览器开发者工具
```
F12 或 Cmd+Option+I
- Console: 查看JavaScript日志
- Network: 查看API请求和响应
- Application: 查看缓存和Cookie
```

### 2. 对比API调用
在诊断页面和主应用中测试相同的文档路径，对比结果。

### 3. 查看完整响应
诊断页面会显示API的完整JSON响应，比主应用的提示更详细。

### 4. 清除缓存
如果修改了代码，确保清除浏览器缓存：
```
Mac: Cmd + Shift + R
Windows/Linux: Ctrl + Shift + R
```

## 📊 成功案例

### 案例1: 端口检测问题
**问题**: 主应用显示"无法连接到服务器"  
**诊断**: 使用诊断页面发现Flask运行在5051端口，但前端查找5050  
**解决**: 修改`detectAPIEndpoint`方法的端口检测顺序

### 案例2: 事件绑定失败
**问题**: 按钮点击无反应  
**诊断**: 诊断页面的按钮工作正常，说明API没问题，是前端事件绑定的问题  
**解决**: 修复事件监听器的绑定时机

### 案例3: 文件路径问题
**问题**: 文档加载失败  
**诊断**: 诊断页面显示"Path is not a file"错误  
**解决**: 发现路径是目录而不是文件，更新API以支持目录扫描
